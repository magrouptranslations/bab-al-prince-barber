# باب البرنس — Bab Al Prince Barber

موقع حلاقة وعناية رجالية باللغة العربية، يشمل صفحات الخدمات، العضوية، الخدمات المنزلية، المتجر، التواصل، ولوحة التحكم التجريبية.

## التشغيل
افتح `index.html` مباشرة أو شغّل المشروع عبر خادم محلي.

## الصفحات
- `index.html` — الرئيسية
- `services.html` — الحلاقة والخدمات
- `membership.html` — العضوية
- `home-services.html` — الخدمات المنزلية
- `shop.html` — المتجر
- `about.html` — من نحن
- `contact.html` — التواصل
- `admin.html` — لوحة التحكم
