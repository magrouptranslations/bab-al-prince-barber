باب البرنس — النسخة الموسعة
===========================

طريقة التشغيل
-------------
1) فك ضغط الملف كاملًا في مجلد عادي على جهازك.
2) شغّل START_SITE.bat بالنقر المزدوج.
3) لا تحتاج Python أو Node.js أو أي تثبيت إضافي.
4) المشغّل يستخدم PowerShell الموجود أصلًا في Windows ويختار منفذًا متاحًا تلقائيًا بين 8765 و8795.
5) بعد نجاح التشغيل ستفتح الصفحة الرئيسية تلقائيًا.

الصفحات العامة
--------------
- index.html            الرئيسية الموسعة
- services.html         الحلاقة الرجالية + الأسعار + شرح الجلسة
- membership.html       باقة البرنس والعضوية بالتفصيل
- home-services.html    الحلاقة والمساج المنزلي
- shop.html             متجر المنتجات الديناميكي
- about.html            من نحن وفلسفة العلامة
- contact.html          التواصل والأسئلة الشائعة
- admin.html            لوحة التحكم

لوحة التحكم
-----------
يمكنك من لوحة التحكم:
- متابعة الحجوزات وتأكيدها.
- تعديل أسماء الخدمات والأسعار والمدد والوصف وحالة الظهور.
- تعديل الباقة ومحتواها وسعرها ومدتها.
- إضافة المنتجات الفعلية للمتجر.
- تعديل اسم العلامة والمدينة والحي والعنوان والجوال والواتساب وساعات العمل.
- تعديل الأسئلة الشائعة وإضافة أسئلة جديدة.
- تشغيل أو إخفاء خدمة التوصيل المدرسي.

إيقاف الخادم
------------
شغّل STOP_SITE.bat.

إذا منع Windows تشغيل PowerShell
---------------------------------
- انقر بزر الماوس الأيمن على START_SITE.bat واختر Run as administrator مرة واحدة.
- الخادم يعمل محليًا على 127.0.0.1 ولا ينشر الموقع على الإنترنت.

مهم
----
لا تفتح index.html بالنقر عليه مباشرة إذا أردت أن تعمل الحجوزات ولوحة التحكم تحت نفس التخزين المحلي. استخدم START_SITE.bat دائمًا.
